## 2b. Rebuild aiter — do this after ANY aiter update, before measuring

`aiter/jit/core.py:1592` rebuilds a module only when its `.so` is **missing** or the
arch changed. There is no source-hash or mtime check, so `git pull` alone leaves every
existing `.so` in place and you measure new Python over old kernels. After the
163-commit update here, 125 of 126 `.so` were still 2026-09-13 binaries from
`4ad998328`.

```bash
B=/sgl-workspace/aiter_jit_backup_$(date +%Y%m%d); mkdir -p $B/so
cd /sgl-workspace/aiter
mv aiter/jit/build aiter/jit/flydsl_cache $B/ && mv aiter/jit/*.so $B/so/
AITER_USE_SYSTEM_TRITON=1 PREBUILD_KERNELS=1 GPU_ARCHS=gfx950 \
  PYTORCH_ROCM_ARCH=gfx950 python3 setup.py develop > /shared_nfs/kk/aiter_rebuild.log 2>&1
# verify: 126 modules, all FlyDSL AOT groups "0 failed", version string = new sha
rg -c 'finish build' /shared_nfs/kk/aiter_rebuild.log
rg -o 'AOT: compiled [0-9]+ ok, [0-9]+ failed' /shared_nfs/kk/aiter_rebuild.log
rg -o 'amd-aiter==[0-9a-z.+g]*' /shared_nfs/kk/aiter_rebuild.log | tail -1
```

~23 min on this node. `PREBUILD_KERNELS=1` front-loads everything except tune and most
mha variants, which is what produces the ~126 `.so`; the default (0) would instead JIT
each module on first use and stall the first server startup.

The FlyDSL cache is safe either way — `flydsl/compiler/jit_function.py` sha256s kernel
sources into the cache key — but clearing it costs nothing since `setup.py` regenerates
it via `run_aot()`.

All 23 runbook AIPerf flags are reproduced verbatim, **including

## 7. Operational notes worth keeping

- VRAM release after a run is **slow**: `rocm-smi` can report tens of GB still used
  for several minutes with `/sys/class/kfd/kfd/proc/` already empty. It does clear.
  Don't `--gpureset` on that evidence alone, and don't start the next arm until it is
  back to ~297 MB — the runbook's `mem-fraction-static 0.65` + 40 GiB MORI heap uses
  essentially the whole card.
- `max_running_requests=128` in the log at `--max-running-requests 1024` is correct:
  it is the per-DP-rank share at dp8.
- Kill servers by PID from `pgrep -f sglang.launch_server`; a broad `pkill -9 -f sglang`
  can match and kill your own shell.
