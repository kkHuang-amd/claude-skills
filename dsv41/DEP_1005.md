## Done (summary)

1. **NaN crash in DP attention + TP MoE decode CUDA graph -- FIXED** (commit `cb5b0b1cdc`). Root cause = aiter custom
   all-gather / reduce-scatter captured with *registered graph-pool inputs* deliver stale peer data over IPC on replay
   (both, independently: AG gave ~3.4e38 garbage rows, RS turned clean partials into NaN), plus MAX_LEN pad rows holding
   stale pool memory fed to the MoE. Chain: MoE NaN -> DSpark verify logits NaN -> bonus = vocab_size -> draft embed OOB
   -> HSA 0x1016. Fix: `SGLANG_AITER_CAPTURE_COPY_IN` (default 1; stage AG/RS inputs through the pre-registered IPC pool
   during capture) + `SGLANG_DP_MASK_PAD_ROWS` (default true; real per-rank count via `num_token_non_padded`, written
   before every decode replay, pad rows zeroed before the gather). Kernel barriers verified correctly paired
   (Signal._flag compared on 3536 step pairs); AR was never on the registered path (0 registrations with copy-in).

   moe_a2a none and attn_dp_size == tp_size. Eager forwards all-gather every rank's late-layer row count; at layer 21
   all ranks switch DP gather sizes (SUM_LEN) and restore after layer 39. DEP (a2a) still rejected.
