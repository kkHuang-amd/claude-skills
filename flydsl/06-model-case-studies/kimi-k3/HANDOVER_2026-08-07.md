```text

BF16 retrieval:               12/12
FP8 retrieval:                12/12
response text identical:      12/12
max aligned logprob diff:     0.002064
```

Why it won:

- FP8 halves the bandwidth-dominant long-context KV traffic.
- DCP8 shards that working set across ranks.
- AITER fused RoPE/quant/cache-write avoids separate write materialization.
- AITER Gluon/persist MLA reads native FP8 and descales inside the kernel.
- Page size 32 matches the Gluon tile and DCP page-table layout.
- DCP-specific base-2 LSE reduce/merge stays fused and page-aware.
