## Runtime configuration

```bash
export SGLANG_K3_KDA_FUSED_BACKEND=aiter
```

This is the gate for the complete fused KDA boundary. When unset, model
initialization and decode preserve the existing KDA path. When set to `aiter`,
the model prepares deferred `f_b` state and dispatches only if the gfx950
implementation and runtime contracts pass; unsupported inputs fail closed.

Exact C2 automatically receives the WPE3/cooperative/front-specialized/
fused-reduction/`fdot2` winner. C1 and C4+ retain their original fused-kernel
options. The source selector defaults to `auto` and prefers the vendored
SGLang kernel. `SGLANG_K3_AITER_KDA_GROUP64` remains independent and optional.
