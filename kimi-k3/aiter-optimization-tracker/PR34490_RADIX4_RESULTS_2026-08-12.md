# SGLang #34490 Radix-4 Kimi-K3 router results — 2026-08-12

## Decision

Accept the Radix-4 Kimi-K3 router as a retained, default-off integration
candidate:

```bash
SGLANG_K3_RADIX4_TOPK=1
```

It passed focused correctness, fresh-JIT dispatch, operator, five-round paired
C2, full C4-C32, GSM8K 200 and capacity gates. Do not enable it by default
until the local correctness fixes are reconciled with upstream #34490.

Local changes relative to upstream #34490:

1. default-off `SGLANG_K3_RADIX4_TOPK` gate;
2. explicit gfx942/gfx950 architecture guard;
3. NaN ranking values are excluded like AITER;
4. exact pivot ties use AITER's deterministic wave64 priority;
5. the deterministic tie path only runs for a full-key tie, preserving the
   normal early-exit fast path.

The initial upstream kernel failed local all-tie and NaN tests. Atomic winner
collection also produced different tie sets across repeated runs. These issues
were fixed before performance validation.

## Combined Radix-4 + B2 exploratory result

Enabled together:

```bash
SGLANG_K3_RADIX4_TOPK=1
SGLANG_K3_AITER_MOE_PREROUTE_FP8=1
SGLANG_K3_AITER_B2_FUSIONS=1
```

Single matched run:

```text
C2 total throughput: 1082.78 tok/s
C2 output throughput: 120.31 tok/s
C2 TPOT:              15.71 ms

C4 total throughput: 1781.59 tok/s
C4 output throughput: 197.95 tok/s
C4 TPOT:              18.68 ms
```

C2 is +9.03% over Radix-4 alone, +2.71% over the prior B2-only result and
+11.58% over the contemporaneous paired baseline median. C4 is +0.22% over
Radix-4 alone, consistent with the B2 path failing closed for M>=4.

This confirms that the two paths can compose, but it is one run rather than a
five-round paired result. Keep the combined profile optional pending repeated
validation.
