# AITER #4572 attention-residual evaluation — 2026-08-11

## Scope

Extracted only the final #4572 attention-residual implementation and ran it
under the validated Torch 2.9.1 / Triton 3.6 environment. No #4568,
chunk-delta-attention, MLA, or Triton 3.7 changes were included.

The production-relevant gate path included:

- pending residual add;
- output RMSNorm;
- hidden size 7168;
- decode token counts 1–128;
- 1, 2, 4, and 8 bank rows.

## Validation

- Upstream gate tests: 64 passed.
- All 32 comparison shapes completed on gfx950.
- Outputs remained within the upstream-style tolerance.

## Microbenchmark

Compared with SGLang's current MI355X-specialized `attn_res_hip`:

```text
32 shapes tested
#4572 faster on 2
current/#4572 median ratio: 0.917x
```

The current kernel won 30/32 shapes. At 8 bank rows, #4572 was roughly
3–4× slower because the current kernel keeps the full bank tile in registers.

The only repeatable opportunity was `N=1, bank_rows=1`:

```text
current median: 9.122 us
#4572 median:   8.785 us
speedup:        1.037x
paired wins:    9/9
```

## Selective endpoint result

An opt-in dispatch used #4572 only for `N=1, bank_rows=1`; every other shape
kept the current SGLang kernel.

```text
C2 throughput: 969.04 -> 969.84 tok/s  (+0.08%)
C2 median TTFT: 941.41 -> 943.89 ms
```

All 16 measured requests succeeded, but the difference is endpoint noise and
TTFT did not improve.

## Fresh-cache dispatch audit

A fresh Triton cache and explicit C1 trace confirmed:

```text
23 launches   attnres_fwd_kernel
349 launches  current _agg_kernel
```

The candidate is not stale, but its coverage is narrower than the C2 gate:
`tokens=1`, `bank_rows=1`, and no fused bank write. Fixed-length C2 requests
remain at batch 2 and finish together, so the C2 result does not strongly
measure this corner.

## Decision

Do not enable #4572 broadly: the current SGLang kernel wins 30/32 shapes.
Reclassify the selective N1/B1 corner as coverage-inconclusive rather than
endpoint-rejected. Run a fresh-cache C1 paired A/B before a final decision.
Temporary AITER/SGLang changes were removed; no commit was created.
