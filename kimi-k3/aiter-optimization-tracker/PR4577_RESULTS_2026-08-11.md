# AITER #4577 GDR KDA decode evaluation — 2026-08-11

## Scope

Evaluated #4577's FlyDSL recurrent KDA decode on the validated Torch 2.9.1 /
Triton 3.6 stack and 8× MI355X.

The experiment had two stages:

1. compare #4577 with SGLang's current Triton recurrent KDA kernel;
2. run an isolated endpoint profile that disables the production AITER
   fully-fused KDA boundary and dispatches #4577 instead.

KDA prefill remained on Triton.

## Fresh-cache dispatch audit

A fresh cache C4 trace observed 69 launches of:

```text
gdr_decode_bf16_kh12x128_vh12x128_q1_4w4x16_vs4_kda_0
```

The candidate was active at the same covered batch size where the endpoint
regressed. Stale JIT is ruled out.

## Decision

Reject #4577 for the current production profile. It accelerates only the
recurrent update, while the existing AITER path fuses conv1d, delta rule,
gated RMSNorm, and `f_b`; losing that larger fusion costs more than #4577
saves.

The temporary AITER and SGLang integration was removed. No commit was created.
