# Kimi-K3 Triton 3.6 A/B — 2026-08-13

## Outcome

Replacing Triton 3.7 with the handover's exact Triton 3.6 commit recovered the
high-concurrency endpoint regression. C2-C32 all passed the 0.5% handover gate
after a focused C4 repeat. The first C4 run was 1.67% low; the repeat was 0.10%
above the handover value.

All requests succeeded, no runtime error was recorded, and capacity remained
933,883 tokens.

Triton 3.6 improved C8/C16/C32 over 3.7 by approximately 1.69%, 2.98% and
5.01%, respectively. The widening recovery mirrors the prior widening
regression, identifying Triton 3.7 as the main high-concurrency cause.

## Decision

Use Triton `3.6.0+git42270451` for the handover-equivalent runtime. Do not use
the tested Triton 3.7 build as the production performance baseline.

The full C2-C32 matrix is reproduced. Treat the first low C4 point as a
single-run outlier, while retaining both logs.
