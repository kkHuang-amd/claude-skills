   - Each AR costs at most 124 us at 64 KB. For comparison, MI355X custom AR is about 10-20 us.

### fp32 WMMA lane layout on gfx1250 (measured, `kernels/wmma_f32_layout_probe.py`)

`rocdl.wmma_f32_16x16x4_f32(vec8f32, a: vec2f32, b: vec2f32, c: vec8f32)` (raw MLIR `flydsl._mlir.dialects.rocdl`), wave32. One-hot probes give:
- A (16 rows x 4 k): lane l holds row `l % 16`; slot s holds `k = 2*(l//16) + s`.
- B (4 k x 16 cols): lane l holds col `l % 16`; slot s holds `k = 2*(l//16) + s`.
- C/D (16 x 16): element (m, n) is in lane `n + 16*(m//8)`, VGPR `m % 8`.
- A and B share the k assignment, so any physical-k permutation works if both use the same one.
- Gotcha: a 256-bit `BufferCopy` (8 x f32) fails in LLVM ("Do not know how to expand this operator's operand"). Buffer loads/stores top out at 128 bits; split them.
