## Observations

- **EP1 wins at low concurrency** (1k/1k c <= 16, 8k/1k c <= 4, and P90 interactivity at 70k c <= 4),
  by up to ~10% on both TTT/GPU and P90 interactivity: decode-dominated, where the EP1 grouped CSV v3
  (n_warp=2 tiles, persistent gemm2) applies.
- **EP8 wins at high concurrency and long prompts** (1k/1k c >= 32 and 8k/1k c >= 16 by 2-4% TTT/GPU;
  70000/300 c >= 4 by ~5%). Median TTFT is lower with EP8 at every point (5-8%): prefill is faster on EP8.
  The EP1 CSV only tunes decode token counts (1-64); prefill (1024/8192-token chunks) runs default tiles,
  where the 512-tiny-expert EP1 shape is ~15% slower (see the MoE probe sections of `MI455_RUN_h13-17.md`).
- Crossover is about 32 concurrent requests for 1k/1k and about 8-16 for 8k/1k.
- Next candidates: tune EP1 prefill rows (token 1024 / 8192) and EP8 decode rows; the remaining c=64 time is
  mostly all-reduce wait from per-socket clock desync.
